# Solidarity Health Network - Marketing Site

Premium marketing website for Solidarity Health Network.

## Tech Stack
- Next.js 16 + TypeScript
- Tailwind CSS
- Framer Motion animations

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Pages
- `/` - Homepage
- `/about` - About page
- `/contact` - Contact page
- `/how-it-works` - How it Works

## Customization Notes
This site was cloned from the TrueCare template. Update the following:
- Brand colors in `app/globals.css` and `tailwind.config.ts`
- Logo in Header/Footer components
- Content text throughout all pages
- Images in `/public` folder
